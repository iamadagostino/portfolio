- **deps**: update dependencies and configure isolated node_modules via .npmrc (`7779b88`)

  Updated project dependencies to the latest compatible versions and added
  a `.npmrc` configuration to isolate `node_modules` in `node_modules.nosync`.

  This ensures:
  - dependencies are installed into `node_modules.nosync/.pnpm`
  - a symlink exposes `node_modules` → `node_modules.nosync` for tooling
  - iCloud Drive ignores the `.nosync` folder, preventing large, unnecessary
    uploads of `node_modules`
  - avoids pnpm "Unexpected virtual store location" errors by explicitly
    defining `virtual-store-dir` in `.npmrc`

  Motivation:
  iCloud was previously syncing `node_modules`, causing performance and
  storage issues. Using `.nosync` combined with pnpm’s `node-linker=isolated`
  and `virtual-store-dir` resolves this problem while keeping developer
  experience intact.

  Refs: pnpm docs on node-linker and virtual store configuration
